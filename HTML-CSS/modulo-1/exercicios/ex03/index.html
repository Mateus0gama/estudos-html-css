Parágrafos e quebras de linhas!

Você pode escrever um parágrafo de qualquer jeito. Basta colocar tudo no meio do par de tags p e /p

Se precisar quberar o texto em algum lugar específico
como esse, você pode usar a tag br

Vamos adicionar alguns simbolos especiais: ® © ™ € £ ¥ ¢ Δ

Vamos adicionar alguns emojis: 🤓 🖖
Para adicionar alguns emojis, devemos pesquisar pelo o mesmo e pegar o código Hexadecimal do mesmo.
Emoji sempre ter que ter &#x antes dos números hexadecimal.
