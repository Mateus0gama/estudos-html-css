# 🌐 Trilha Frontend: HTML5 e CSS3

Este repositório documenta todo o meu processo de aprendizagem, anotações e exercícios práticos construídos durante o curso de HTML5 e CSS3 do professor Gustavo Guanabara (Curso em Vídeo).

O objetivo deste projeto é dominar a base estrutural e visual do desenvolvimento web, cobrindo do Módulo 1 ao Módulo 5. Essa trilha de frontend é um passo essencial para complementar meus estudos em engenharia de software e análise de sistemas, criando a ponte visual para integrações futuras com lógicas de backend.

## 📚 Estrutura de Módulos

- **Módulo 1:** História da Web, funcionamento da internet, semântica básica do HTML5, links e mídias.
- **Módulo 2:** Fundamentos do CSS3, teoria das cores, tipografia e o conceito fundamental de _Box Model_ (Modelo de Caixas).
- **Módulo 3:** Imagens de fundo, criação e estilização de tabelas de dados e estruturação de formulários.
- **Módulo 4:** Princípios de responsividade, _Media Queries_, _Mobile First_ e incorporação com iframes.
- **Módulo 5:** Desafios de layout e aplicações práticas modernas (preparando o terreno para Flexbox e CSS Grid).

## 🚧 Desafios e Aprendizados Esperados

Durante a evolução destes cinco módulos, o foco será dominar alguns dos maiores desafios do desenvolvimento web inicial:

1. **A Guerra da Especificidade do CSS:** Entender exatamente qual regra estilística tem prioridade quando múltiplas classes e IDs tentam modificar o mesmo elemento.
2. **O Domínio do Box Model:** Aprender a calcular e ajustar `margin`, `padding` e `border` sem quebrar a largura total do layout da página.
3. **Design Responsivo:** Mudar a mentalidade para o _Mobile First_, garantindo que os projetos funcionem perfeitamente em telas de smartphones antes de expandirem para monitores desktop.
4. **Organização de Código:** Manter arquivos HTML limpos (focados em semântica) e arquivos CSS modulares, evitando repetição de código desnecessária.

## 💻 Ambiente de Desenvolvimento

Os exercícios e testes deste repositório são executados sob o seguinte ambiente:

- **Linguagens:** HTML5 e CSS3.
- **Versionamento:** Git e GitHub (commits e gerenciamento de chaves SSH realizados diretamente via terminal).
- **Sistema Operacional:** Linux Mint.
- **Paradigma:** Construção estática com foco em semântica W3C.
